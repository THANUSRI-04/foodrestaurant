🔐 Admin Account Management Guide

To add or promote an authorized hotel manager to Admin:

  1. Create the account via Firebase Console → Authentication or register on the website.
  2. In Firebase Realtime Database, navigate to users/{uid}.
  3. Set the field "role": "admin".
  4. The administrator can now log in securely through /admin/login.html.
